# Linux Filesystem Core Directories

## /

The root directory `/` is the top-level directory in Linux; every file and folder exists somewhere beneath it.

## /bin

`/bin` contains essential user command binaries like `ls`, `cp`, and `mv` that are required for basic system operation.

## /etc

`/etc` stores system-wide configuration files that control how the operating system and services behave.

## /home

`/home` contains personal directories for each user, where user-specific files and data are stored.

## /var

`/var` holds variable data such as logs, caches, mail, and application runtime files that change frequently.

## /usr

`/usr` contains user-level programs, libraries, and utilities that are not essential for booting but are required for normal system use.
