# Project 03 – Linux Filesystem Awareness

## Overview

This project focuses on understanding the Linux filesystem structure and improving terminal navigation skills.

The goal is to become confident moving around directories and understanding what core system folders are responsible for.

Environment: Ubuntu 24.04 (WSL2)

---

## Objectives

- Understand the Linux root directory (`/`)
- Identify the purpose of core system folders
- Practice navigation using `cd`, `ls`, and relative paths
- Understand absolute vs relative paths
- Build filesystem awareness without relying on GUI tools

---

## Skills Practiced

- `pwd`
- `ls`
- `ls -l`
- `cd`
- `cd ..`
- `cd /`
- `which`
- Relative paths (`../`)
- Absolute paths (`/home/ravi/...`)

---

## Key Concepts

### Root Directory `/`

All files and directories in Linux exist under `/`.

### Absolute vs Relative Paths

- Absolute paths start from `/`
- Relative paths depend on your current working directory

### Directory Traversal

Using `cd ..` moves one directory up in the hierarchy.

---

## Why This Matters

Understanding the filesystem is foundational for:

- Linux administration
- Cloud engineering
- Containerisation
- DevOps
- Debugging production systems

Without filesystem awareness, troubleshooting becomes guesswork.

---

## Reflection

Today’s focus was slow and deliberate navigation practice.  
Instead of jumping quickly between folders, I practiced:

- Moving up one level at a time
- Checking my location with `pwd`
- Confirming contents with `ls`

This reinforces awareness of where I am in the system — a critical skill when working on remote servers or production environments.
